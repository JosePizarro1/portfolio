# Portfolio de Jose Pizarro

Bienvenido a mi portafolio personal. Este es un proyecto moderno desarrollado con **Next.js 14**, diseñado para mostrar mis habilidades, proyectos y experiencia de una manera elegante y profesional.

## 🚀 Descripción del Proyecto

Este portafolio utiliza una estética de "Modo Oscuro" premium con animaciones fluidas y un diseño responsive orientado a la experiencia del usuario. Incluye secciones para una presentación personal, listado de habilidades técnicas, galería de proyectos detallada y un formulario de contacto funcional.

## ✨ Características Principales

-   **Diseño Moderno**: Interfaz oscura con degradados vibrantes y efectos de glassmorphism.
-   **Animaciones Avanzadas**: Implementación de `framer-motion` para transiciones y efectos de entrada suaves.
-   **Galería de Proyectos**: Sección detallada que muestra trabajos recientes, incluyendo el sistema **Centro Salud Esperanza**.
-   **Diseño Responsive**: Totalmente adaptable a dispositivos móviles, tablets y escritorio.
-   **Tecnología 3D**: Integración de elementos 3D dinámicos usando `Three.js` (React Three Fiber).

## 🛠️ Tecnologías Utilizadas

-   **Core**: [Next.js 14](https://nextjs.org/) (App Router)
-   **Lenguaje**: [JavaScript](https://developer.mozilla.org/es/docs/Web/JavaScript) / [TypeScript](https://www.typescriptlang.org/)
-   **Estilos**: [Tailwind CSS](https://tailwindcss.com/)
-   **Animaciones**: [Framer Motion](https://www.framer.com/motion/)
-   **Iconos**: [Lucide React](https://lucide.dev/)
-   **Componentes UI**: Radix UI
-   **Efectos 3D**: React Three Fiber / Drei / Three.js

## 📁 Estructura del Proyecto

```bash
/app           # Rutas y estructura principal de la aplicación (Next.js App Router)
/components    # Componentes modulares reutilizables (Hero, Navbar, Projects, etc.)
/public        # Archivos estáticos
  ├── /img     # Imágenes de los proyectos y recursos visuales
  └── /pdf     # Documentos y CVs
/styles        # Configuraciones globales de CSS y Tailwind
/node_modules  # Dependencias del proyecto
```

## ⚙️ Comandos Disponibles

Para ejecutar este proyecto de forma local, sigue estos pasos:

1.  **Instalar dependencias**:
    ```bash
    npm install
    ```

2.  **Iniciar el servidor de desarrollo**:
    ```bash
    npm run dev
    ```
    El proyecto estará disponible en `http://localhost:3000`.

3.  **Construir para producción**:
    ```bash
    npm run build
    ```

4.  **Iniciar la versión de producción**:
    ```bash
    npm run start
    ```

5.  **Ejecutar Linter**:
    ```bash
    npm run lint
    ```
